# tessera

=^..^=  version 1 (2026)  Sofia Vallejo Budziszewski, IEM KUG Graz Austria

One Pure Data library with two halves that look and behave alike: ten classic synth architectures and seven
creative effects. Clean graph-on-parent GUIs, lowercase help patches with pages, presets, A/B morph, mutate,
a data inlet and stash-ready parameter names on everything. Sibling of stash, mcx, lumen and kvx.

## Synths (`synths/`)

| object | architecture |
| --- | --- |
| `dx7~` | 6-operator FM with SysEx support and a patch browser |
| `tx81z~` | 4-operator FM, 8 waveforms, 8 algorithms |
| `minimoog~` | three-oscillator monosynth with ladder filter |
| `sh101~` | monophonic synth |
| `alphajuno~` | 6-voice synth with chorus |
| `prophet5~` | 5-voice polysynth with poly-mod |
| `b3~` | tonewheel organ with rotary speaker |
| `ms20~` | monosynth with screaming filters and patch matrix |
| `cz101~` | phase distortion synth |
| `mellotron~` | tape keyboard for your own wav files |

The names describe architectures. They are not copies of any ROM or circuit and were not compared with hardware.
More in `synths/README.md` and each synth's folder.

## Effects (`fx/`)

| object | what it does |
| --- | --- |
| `freeze~` | holds the spectrum and keeps it sounding |
| `smear~` | blurs the spectrum over time and frequency |
| `gate~` | keeps only the strongest bins, can be inverted |
| `cross~` | cross-synthesis between two inputs |
| `grain~` | pitch-aware granulator: grains follow the detected pitch, scale snapping, reverse probability, scrub by data |
| `modal~` | modal resonator bank: glass, wood, bell, plate, bar, string, tube, bowl, or modes learned from a sound |
| `datamod~` | data modulators: CSV columns, lists, Pd arrays, Lorenz, Henon, cellular automata as four control signals |

Use them as `[tessera/freeze~ f1]`. Always give each effect instance its own name (see below).
More in `fx/README.md`.

## Shared features

* presets: `preset n|name`, `next`, `prev`, `store`, `save`, `load`
* A/B morph: `A`, `B`, `morph 0..1`
* `mutate 0..1`: random variation of the current sound
* data inlet: `data 0..1` and `datamap <param> <amount>`; `datamod~` can drive any of them
* stash-ready names: `<name>-<param>` to send, `<name>-<param>-r` to receive. Naming only, not tested with stash yet.

## Build (one CMake for everything)

```
cmake -S . -B build -DPD_INCLUDE_DIR=/Applications/Pd-0.55-1.app/Contents/Resources/src
cmake --build build
cmake --install build --prefix /Users/you/Documents/PdProjects/externals
```

This puts a `tessera` folder (14 externals, abstractions, help patches) into the prefix. Without `--prefix`
it goes to `build/dist/tessera`, ready for `deken package build/dist/tessera`. Mac builds are universal
(arm64 and x86_64) and not notarised (no Apple Developer account). If macOS blocks them:
`xattr -dr com.apple.quarantine /path/to/tessera`. Linux works the same way. For Windows pass `-DPD_LIB=path/to/pd.lib`
(untested). Needs Pd with 32-bit floats (the default).

## Tests

Offline, no Pd needed: `cmake -S . -B build -DPD_INCLUDE_DIR=... -DBUILD_TESTS=ON`, build, then `ctest --test-dir build`.
Also `make -C fx/test asan` (ASan and UBSan) and, with a real Pd,
`python3 fx/test/pd_smoke.py path/to/pd/bin/pd folder-containing-tessera`, which renders every effect headless.
Not tested: the GUI panels in a real Pd window, stash, Windows, listening quality, anything on a Mac.

## Layout

`fx/` effects (`src`, `abs`, `help`, `tools`, `test`), `synths/` synths (`common`, one folder per synth, `tools`, `test`).
The help patches and abstractions are generated by `fx/tools/make_fx.py` and `synths/tools/` from the same parameter
tables the engines use, so the GUI cannot disagree with the sound engine.
